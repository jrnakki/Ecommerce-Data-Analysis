# 🛒 E-Commerce Data Analysis Using Python

A beginner-friendly **Data Analysis project using Python** that simulates e-commerce transactions and analyzes sales data to extract meaningful business insights.

This project generates 10,000 synthetic e-commerce transactions and analyzes revenue, product performance, sales quantities, and payment preferences.

---

## 📌 Project Overview

E-commerce platforms generate large amounts of transactional data every day. Analyzing this data helps businesses understand their sales performance and make better decisions.

This project demonstrates how Python can be used to:

- Generate synthetic e-commerce transaction data.
- Read and process CSV datasets.
- Calculate total sales and revenue.
- Identify popular products and payment methods.
- Compare revenue generated by different products.
- Extract useful business insights.

## 🎯 Project Objectives

1. Generate a dataset containing 10,000 e-commerce transactions.
2. Process and analyze transactional data using Python.
3. Calculate important sales and revenue metrics.
4. Identify the best-performing products.
5. Understand customer payment preferences.

## 📊 Dataset Description

The project generates 10,000 synthetic transactions.

| Column | Description |
|---|---|
| Transaction_ID | Unique transaction identifier |
| Customer_ID | Customer identifier |
| Product | Purchased product |
| Quantity | Number of units purchased |

## ⚙️ Features

### 1. Transaction Data Generation

- Generates 10,000 random transactions.
- Assigns random customer IDs.
- Selects products and payment methods.
- Assigns product prices and purchase quantities.
- Stores generated data in a CSV file.

### 2. Data Analysis

The analysis program calculates:

- Total number of transactions.
- Total revenue generated.
- Total quantity of products sold.
- Product-wise sales quantity.
- Product-wise revenue.
- Most popular product.
- Highest revenue-generating product.
- Most popular payment method.
- Percentage of UPI transactions.
- Least popular payment method.
- Average transaction value.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Project Folder

```bash
cd Ecommerce-Data-Analysis
```

### Step 3: Generate Transaction Data

```bash
python src/generate_data.py
```

This generates the `transactions.csv` file inside the `data` folder.

### Step 4: Run Data Analysis

```bash
python src/analyse_data.py
```

The program displays the calculated sales and revenue statistics in the terminal.

## 💡 Key Business Insights

- A product with the highest quantity sold may not necessarily generate the highest revenue.
- Product-wise revenue helps identify financially valuable products.
- Payment method analysis helps understand customer payment preferences.
- Average transaction value provides an overview of spending per transaction.
